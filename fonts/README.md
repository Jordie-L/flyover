# Fonts

X11 "misc-fixed" bitmap fonts, Unicode versions by Markus Kuhn
(<https://www.cl.cam.ac.uk/~mgk25/ucs-fonts.html>), taken from the
[rpi-rgb-led-matrix](https://github.com/hzeller/rpi-rgb-led-matrix/tree/master/fonts)
repository. They are public domain ("Public domain font. Share and enjoy.").

To keep the repository small, each file is cut down to Latin text (code points
below U+0250), arrows (U+2190-2199), and a few symbols (bullet, ellipsis, minus,
triangles). Nothing else was changed.

| File | Cell size | Used for |
|---|---|---|
| `4x6.bdf` | 4x6 | Smallest labels |
| `5x7.bdf` | 5x7 | Secondary lines |
| `6x10.bdf` | 6x10 | Main lines |
| `7x13B.bdf` | 7x13 bold | Emphasis |
| `10x20.bdf` | 10x20 | The clock |
